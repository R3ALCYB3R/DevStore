# 🚀 DevStore

A sleek, native iOS application ecosystem designed to handle seamless sideloading, application tracking, and advanced developer utilities. Built from the ground up to provide a smooth, self-hosted deployment experience optimized for devices running **iOS 13 and higher**.

---

## ✨ Features

* **Wide Compatibility:** Full native support for iOS 13 through modern firmware versions.
* **On-Device Management:** Wirelessly track app lifecycles, installation states, and updates directly from your device.
* **Integrated JIT Utilities:** Built-in hooks to quickly initialize Just-In-Time compilation for advanced emulation and development tools.
* **Unified Environment:** Clean, responsive UI built to centralize your app catalogs into a single, high-performance interface.

---

## 🛠️ Automated Compilation

This repository utilizes cloud-based CI/CD automation to compile the application source binaries into a ready-to-install package without requiring a local development environment.

### How to Build:
1. Open this repository on your profile.
2. Click on the **Actions** tab in the top menu bar.
3. Select the primary build workflow from the left-hand sidebar.
4. Click the **Run workflow** dropdown on the right and trigger the compilation.
5. Once complete, download the packaged binary artifact directly from the build summary page.

---

## 🔒 Architecture & Security

DevStore utilizes secure, local sandbox communication to manage application profiles. All operations are kept completely on-device to ensure privacy, integrity, and absolute control over your environment.
